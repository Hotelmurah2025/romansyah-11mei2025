Hotel Extranet

Manage your hotel properties and bookings

Welcome to Hotel Extranet

This is a simplified version of the Hotel Extranet application. The backend API is fully functional and can be accessed at:

https://app-ohrondfu.fly.dev

The full frontend application is currently being developed. You can use the API endpoints directly for testing.

API Endpoints

  • Health Check: GET /healthz
  • User Registration: POST /auth/register
  • User Login: POST /auth/login
  • User Info: GET /auth/me
  • Hotels: GET, POST, PUT, DELETE /hotels
  • Rooms: GET, POST, PUT, DELETE /rooms
  • Bulk Price Update: PUT /rooms/bulk-price-update
  • Bookings: GET, POST, PUT, DELETE /bookings

Example API Usage

// Register a new user
fetch('https://app-ohrondfu.fly.dev/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'Test User',
    email: 'test@example.com',
    password: 'password123',
    role: 'hotel_owner'
  })
})
.then(response => response.json())
.then(data => console.log(data))
